The url will have the format /type/uuid/url, with type & url en/decoded
When a html is loaded as main_frame, the uv scripts are immediately injected
and are the first pieces of js executed, even if the html doesn't have any js.

When a html is loaded as main_frame, it is given a random uuid set by the service worker.
The url rewrite handler in scripts loaded by that html file will use window.__hv$uuid.
When there is a link elsewhere <a href (example)>, a new uuid is created for that link.
If that link is clicked and you go back, no worries. The html auto-registers and deregisters
uuid's. If the main_frame is not a html, no worries. It can't load any scripts and it's either
blocked or allowed.
